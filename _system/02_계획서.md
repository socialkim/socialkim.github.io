# 02 계획서 · 구조와 시스템 (v1.0 · 2026-09-24)

## 1. 시스템 한 장
```
[새 레포 생성]  ──(매일 09:00 KST)──▶  scripts/discover.py
      │                                  GitHub API로 has_pages 레포 목록
      │                                  → projects.json에 없는 레포를 data/inbox.json에 추가
      │                                    (페이지 <title>·설명·첫 문단 자동 추출)
      ▼
data/projects.json (정리된 원본, 사람이 읽는 JSON)
data/inbox.json    (자동 발견, 정리 전)
data/profile.json  (인물 정보·저서·방송·링크)
      │
      ▼
scripts/build.py  ──▶  index.html / about/ / p/<id>/ / llms.txt / llms-full.txt
                       sitemap.xml / robots.txt / feed.xml
      │
      ▼
.github/workflows/update-hub.yml  → 변경 있으면 커밋 → Pages 빌드 요청
```
- 파이썬 표준 라이브러리만 사용(설치 없음). 소장님 PC·클라우드·Actions 어디서나 `python3 scripts/build.py` 한 줄.
- 정리 루틴: 클로드가 inbox 항목을 읽고 projects.json으로 옮기며 분류·기관·요약을 채운다(스킬 `socialkim-hub-update`).

## 2. 정보 구조
| 페이지 | 역할 | 주 독자 |
|---|---|---|
| `/` 홈 | 한 줄 정체성, 숫자 요약, 최근 공개 6개, 전체 목록(분야 필터), 기관 색인 | 섭외 담당자·수강생 |
| `/about/` 소개 | 약력·저서·방송·하는 일·자주 묻는 질문, Person JSON-LD | AI 검색엔진·섭외 담당자 |
| `/p/<id>/` 프로젝트 상세 | "김덕진 소장이 ○○년 ○월 △△ 대상 □□ 강의에서 쓴 실습 페이지" 근거 문장, 주제·도구, 원본 링크 | AI 검색엔진 |
| `llms.txt` | AI용 요약 + 전체 목록 링크 | LLM 크롤러 |
| `sitemap.xml`·`robots.txt`·`feed.xml` | 색인·AI 크롤러 허용·새 글 알림 | 검색엔진 |

## 3. 분류 체계 (section → sector)
- **강의·실습 `lecture`**
  - `corp` 기업·경영진 / `public` 공공기관·협회·지자체 / `univ` 대학·교육 / `media` 언론·미디어 / `job` 직무·일반
- **만든 것 `build`**: 서비스·도구·MCP 서버·컨설팅 페이지
- **실험실 `lab`**: AI로 만든 게임·실험, 방송 연계·팬메이드
- **아들과 함께 `family`**: 초등학생 아들과 만든 것
- 명함(`/card/`)은 소개 페이지에서 링크.

## 5. AI 가시성 설계
- 모든 목록을 서버 없이 정적 HTML로 출력(JS는 필터 보조만).
- 각 상세 페이지 첫 문단 = 근거 문장. 예: "IT커뮤니케이션연구소 김덕진 소장이 2026년 9월 3일 범농협 최고경영진 AI 세미나에서 사용한 실습 가이드입니다."
- JSON-LD: 홈 `Person`+`ItemList`, 소개 `ProfilePage`+`Person`+`FAQPage`, 상세 `LearningResource`(author·provider·audience·dateCreated).
- robots.txt에 GPTBot·ClaudeBot·PerplexityBot·Google-Extended 등 명시 허용.
- 이름 표기 통일: 김덕진 / Kim Dukjin(kimdukjin), 소속 IT커뮤니케이션연구소(ITCL).
