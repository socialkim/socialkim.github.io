# 언더스탠딩 3D 항해 게임 개발비 시뮬레이션

## 1. 프로젝트 개요

- 프로젝트명: **언더스탠딩: 세상의 모든 지식의 바다**
- 형태: 브라우저에서 실행되는 3D 웹게임
- 주요 기술: HTML, CSS, JavaScript, Three.js, Web Audio API
- 주요 기능:
  - 3D 바다와 파도 표현
  - 선박 이동 및 카메라 추적
  - 지식 구체 수집 시스템
  - 암초, 폭풍, 충돌 판정
  - 부스트 및 파티클 이펙트
  - 효과음과 배경 환경음
  - PC 및 모바일 조작
  - 등대 도착 엔딩
